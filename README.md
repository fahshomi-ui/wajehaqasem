# مكتب الوسيم للخدمات العامة

موقع **مكتب الوسيم للخدمات العامة** (مؤسسة فردية سعودية – الرياض – الرقم الموحد `7038025471`).

يحتوي الموقع على:

- صفحة رئيسية لاختيار نوع تأمين السيارة (**التأمين ضد الغير** و**التأمين الشامل**)؛ كل زر يفتح **واتساب** على الرقم `0581092444` مع رسالة جاهزة بنوع التأمين المختار.
- قسم **من نحن** وقسم **تواصل معنا** يضم العنوان الوطني وبيانات السجل التجاري ورابط التحقق من وزارة التجارة.
- صفحة **سياسة الخصوصية** على `/privacy/`.
- **لوحة تحكم** على `/admin` لتغيير رقم واتساب الأزرار ومعلومات التواصل (الهاتف، البريد) بدون تعديل الكود أو إعادة النشر.

## النشر على Netlify

1. من Netlify اختر **Add new site → Import an existing project → GitHub** واختر هذا المستودع.
2. الإعدادات تُقرأ تلقائياً من `netlify.toml` (لا حاجة لـ Build command، و Publish directory = `public`).
3. كلمة سر لوحة التحكم الافتراضية مضبوطة داخل الكود (`netlify/functions/links.mjs`).
   لتغييرها بدون تعديل الكود أضف متغير البيئة **`ADMIN_PASSWORD`** من **Environment variables → Add a variable**، ثم **Deploys → Trigger deploy** — قيمته تأخذ الأولوية على الافتراضية.
4. اضغط **Deploy**.

## لوحة التحكم

1. افتح `https://اسم-موقعك.netlify.app/admin`
2. أدخل كلمة السر.
3. **رقم واتساب**: الرقم الذي يفتحه زرّا التأمين (ويظهر في قسم التواصل). إذا تُرك فارغاً يُستخدم الرقم الافتراضي `0581092444`.
4. **معلومات التواصل**: رقم الهاتف (الافتراضي `0581092444`) والبريد الإلكتروني (لا يظهر إذا تُرك فارغاً).
   يمكن كتابة الأرقام بالعربية أو الإنجليزية، وبصيغة `05…` أو `+966…`.
5. اضغط **حفظ الإعدادات** — تظهر التغييرات على الموقع فوراً.

الرقم الافتراضي مكتوب أيضاً داخل `public/index.html` و`public/app.js` (`DEFAULT_WHATSAPP`) حتى تعمل الأزرار حتى قبل حفظ أي إعدادات.

لتغيير كلمة السر: عدّل قيمة `ADMIN_PASSWORD` في Netlify ثم أعد النشر.

## التشغيل محلياً

```bash
npm install
ADMIN_PASSWORD=test netlify dev
```

ثم افتح `http://localhost:8888` و `http://localhost:8888/admin`.
