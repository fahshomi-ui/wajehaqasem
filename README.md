# مكتب الوسيم للخدمات العامة

موقع **مكتب الوسيم للخدمات العامة** (مؤسسة فردية سعودية – الرياض – الرقم الموحد `7038025471`).

الموقع بنفس تصميم ومحتوى `amncar.com`: خدمات عامة وتعقيب معاملات، ولا يوجد فيه أي محتوى عن التأمين. يحتوي على:

- صفحة رئيسية بعنوان «معاملاتك أوضح، وخطواتك أيسر.»، وست خدمات لكل منها نافذة تفاصيل وزر استفسار عبر **واتساب**: تعقيب المعاملات، ومتابعة الطلبات، والخدمات الإلكترونية، وتجهيز المستندات، وحجز المواعيد، وخدمات الأفراد والمنشآت.
- أقسام **عن المكتب** و**كيف نعمل**، ونموذج «ما الخدمة التي تحتاجها؟» الذي يجهّز رسالة واتساب، و**الأسئلة الشائعة**.
- صفحة **سياسة الخصوصية** على `/privacy.html`، والرابط القديم `/privacy/` يحوّل إليها.
- شريط **الموافقة على التتبّع**: وسم Google Ads (`AW-18502183012` مع تحويل مشاهدة الصفحة الرئيسية) لا يُحمَّل إلا بعد موافقة الزائر.
- **لوحة تحكم** على `/admin` لتغيير رقم واتساب ورقمي الهاتف والبريد الظاهرة في كل الموقع، بدون تعديل الكود أو إعادة النشر.

## النشر على Netlify

1. من Netlify اختر **Add new site → Import an existing project → GitHub** واختر هذا المستودع.
2. الإعدادات تُقرأ تلقائياً من `netlify.toml` (لا حاجة لـ Build command، و Publish directory = `public`).
3. كلمة سر لوحة التحكم الافتراضية مضبوطة داخل الكود (`netlify/functions/links.mjs`).
   لتغييرها بدون تعديل الكود أضف متغير البيئة **`ADMIN_PASSWORD`** من **Environment variables → Add a variable**، ثم **Deploys → Trigger deploy** — قيمته تأخذ الأولوية على الافتراضية.
4. اضغط **Deploy**.

## لوحة التحكم

1. افتح `https://اسم-موقعك.netlify.app/admin`
2. أدخل كلمة السر.
3. **رقم واتساب**: الرقم الذي تفتحه كل أزرار واتساب ونموذج طلب الخدمة. إذا تُرك فارغاً يُستخدم الرقم الافتراضي `0581092444`.
4. **معلومات التواصل**: رقما الاتصال، الأول (الافتراضي `0581092444`) والثاني (الافتراضي `0581092488`)، ويظهران معاً في قسم الطلب والأسئلة الشائعة وأسفل الموقع، ويتصل زر «تواصل معنا» بالأول. والبريد الإلكتروني ويظهر أسفل الموقع (لا يظهر إذا تُرك فارغاً).
   يمكن كتابة الأرقام بالعربية أو الإنجليزية، وبصيغة `05…` أو `+966…`.
5. اضغط **حفظ الإعدادات** — تظهر التغييرات على الموقع فوراً.

الرقم الافتراضي مكتوب أيضاً داخل `public/index.html` و`public/app.js` حتى تعمل الأزرار حتى قبل حفظ أي إعدادات.
